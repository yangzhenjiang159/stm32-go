# snapshots —— 调试照片存放目录

**把手机拍的画面放在这里，AI 可以直接读取图片来分析。**

## 为什么

调试硬件时，"屏幕上到底显示成什么样"往往是最关键的信息。
纯文字描述容易失真（例如"乱了""一部分在动"），而一张照片信息量抵十轮来回。

## 怎么用

1. 手机拍屏幕 / 接线 / 模块丝印
2. 传到电脑，命名有意义一些，存到本目录，例如：

```
snapshots/
├─ 20260915-lcd-四角方块.jpg
├─ 20260915-lcd-爱心异常.jpg
├─ 20260915-屏幕丝印.jpg
└─ 20260915-排线接线.jpg
```

3. 对 AI 说：**"看 snapshots 里的 xxx.jpg"**

## 拍摄建议

- **屏幕类**：关灯或调暗环境光，避免反光；尽量正对屏幕拍，把整个屏都拍进来（方便判断边界和比例）
- **接线类**：拍清楚插座、排线方向、跳线帽位置
- **丝印类**：给模块正面/背面的型号文字拍特写（型号决定驱动 IC，非常关键）
- **现象类**：如果现象是"闪烁/循环"，可以连拍 2~3 张不同状态的图
