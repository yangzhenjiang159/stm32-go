## 4. 屏幕（3.5" TFT）事实

| 项 | 值 | 出处 | 置信度 |
|---|---|---|---|
| 尺寸/分辨率 | 3.5"，**320×480 竖屏** | 实测 | HIGH |
| 接口 | 2×14（**28 pin**）排针直插开发板 LCD 座 | 实物 | HIGH |
| 驱动 IC | **ILI9488 风格**（读 `0xD3` = `0x9488`） | 实测（`lcd_love/README.md` §1） | HIGH |
| 资料目录命名 | 写的是 **ILI9486**（**命名与实物不符**） | 资料目录名 | HIGH（冲突已裁决，见 C-001） |

### 已实测定型的 6 条配置（照抄，勿改）

| # | 项 | 值 | 依据 |
|---|---|---|---|
| 1 | FSMC 时序 | `ADDSET=15`、`DATAST=255`（HCLK=72MHz） | 实测（36MHz 版时序 → 白屏） |
| 2 | 初始化序列 | ILI9488 风格，**必须含 `0xF7`** | 实测（缺 → 白屏） |
| 3 | 像素格式 | `0x3A = 0x55`（16bit/像素） | 实测（`0x66` → 数据错位、只铺 2/3） |
| 4 | 扫描方向 | `0x36 = 0x08` | 实测 |
| 5 | 复位脚 | **PG15** | 实测（官方例程 `PC5` → 白屏） |
| 6 | 行列地址 | `0x2A/0x2B` 各写 **4 次 8 位值** | 实测（2 次 16 位 → 内容挤成细线） |

### 已知不可靠（勿再尝试）

| 手段 | 实测结果 | 结论 |
|---|---|---|
| 读 GRAM（`0x2E`） | 所有坐标恒为 `0xFCFC` | 读通路不可靠 → **禁止设计读回校验** |
| 读 ID（`0x04`） | 返回 `0x548066`（错误） | 只有 `0xD3` 偶发正确 |
| 全屏纯色测试 | 两种窗口写法"看起来都正常" | **纯色不能验证窗口寻址**，必须用分离小图形（四角方块） |

## 6. 未决问题 / 待实物验证清单（Step 6）

> 这些项**不影响当前功能**，但在做以下事情前必须先测：接传感器/外设并口模块、加串口日志、提高刷新率、使用触摸。

### 待验证 #V-001：3.3V 电源域实际输出与裕量

| 项 | 内容 |
|---|---|
| 目的 | 确认板载 3V3 供给能否带动后续新增模块（LDO 型号目前 `UNKNOWN`） |
| 仪器 | 万用表（电压）；示波器（纹波） |
| 测点 | 屏背光限流电阻 / 任一 3V3 排针与 GND |
| 条件 | 屏幕背光全亮，固件跑满屏刷新 |
| 期望值 | 3.30 V ± 3%（3.20–3.40 V）；纹波 < 50 mVpp |
| 判据 | 若低于 3.20 V 或纹波超标 → 新增模块需独立供电 |

### 待验证 #V-002：HSE 实际频率与波特率误差

| 项 | 内容 |
|---|---|
| 目的 | 为"接 USB-TTL 打串口日志"做准备（波特率误差需 < 2%） |
| 仪器 | 示波器或频率计（探头接 PA8/MCO 或 X1） |
| 测点 | HSE 晶振输出 / MCO 引脚 |
| 条件 | 固件正常运行的稳态 |
| 期望值 | 8.000 MHz ± 100 ppm（HCLK 72.000 MHz） |
| 判据 | 频偏 > 200 ppm → 串口需降速或修负载电容（负载电容当前 `UNKNOWN`） |

### 待验证 #V-003：BOOT0 / NRST 状态

| 项 | 内容 |
|---|---|
| 目的 | 确认上电启动模式与复位电路确定（当前原理图未逐条核对） |
| 仪器 | 万用表（电平）；目视（元件） |
| 测点 | BOOT0 引脚对地、NRST 对 3V3 |
| 条件 | 上电后与复位键按下/松开两种状态 |
| 期望值 | BOOT0 = 0 V（有下拉）；NRST 空闲 = 3.3 V，按下 = 0 V |
| 判据 | BOOT0 悬空/浮空 → 偶发启动异常，需补下拉 |

### 待验证 #V-004：触摸 IC 型号与 I2C 地址（若将来用触摸）

| 项 | 内容 |
|---|---|
| 目的 | 触摸驱动需要确切 IC 型号与 7bit 地址（原理图未标注） |
| 仪器 | 多模态读图（拍屏背面丝印）+ 逻辑分析仪 |
| 测点 | 触摸排线侧 IC 丝印；I2C1（PB6/PB7）总线 |
| 条件 | 上电后固件主动读 0x8140 / 0x814Eh 类寄存器尝试 |
| 期望值 | 期望读到确切 ID（如 GT911 = 0x5D/0x14） |
| 判据 | 读不到 → 不做触摸功能 |
