## 冲突 #001：屏幕驱动 IC 型号命名错配（ILI9486 vs ILI9488）

| 项 | 内容 |
|---|---|
| 严重度 | **Critical** |
| 检查项 | 器件型号 — 屏驱动 IC（对应方案 §6.2 第 3 类：型号/命名错配） |
| 资料说 | 目录名 `3.50LCD焊接37pin-ILI9486技术资料`，其初始化序列按 **ILI9486** 编写 |
| 实物说 | 读 `0xD3` 返回 **`0x9488`** → **ILI9488 风格**，且按其序列（含 `0xF7`）可正常点亮 |
| 原理图说 | **未标注**驱动 IC 型号（`UNKNOWN`） |
| 判定 | **确认不一致**（资料命名与实物不符） |
| 依据 | 实测：照抄 ILI9486 例程序列 → 纯白屏；改用 ILI9488 风格（含 `0xF7` Adjust Control 3）→ 立即出图。详见 `lcd_love/README.md` §1.2 第 1 条、§3 坑 1 |
| 裁决 | **RESOLVED-资料错**（依据优先级第 1 层：实物实测；由人工确认） |
| 影响 | 照抄资料序列 → 白屏，浪费大量排查时间 |
| 状态 | **RESOLVED** |

|---|---|

## 冲突 #004：FSMC 时序按 HCLK=36MHz 编写

| 项 | 内容 |
|---|---|
| 严重度 | **Critical** |
| 检查项 | 时序 — FSMC ADDSET/DATAST（对应 §6.2 第 9 类：时钟/时序不符） |
| 教程/官方说 | 时序注释写 `1/36M = 27ns`，即按 **HCLK=36MHz** 计算 |
| 代码/实物说 | 本板 `system_stm32f10x.c` L114 定义为 **72MHz**（HSE 8MHz × PLLMULL9） |
| 判定 | **确认不一致**（教程板与本板主频不同） |
| 依据 | `lcd_love/README.md` §3 坑 1；实测：36MHz 时序 → 纯白屏；`ADDSET=15 / DATAST=255` → 正常 |
| 裁决 | **RESOLVED-教程错（对本板而言）**（实物实测；由人工确认） |
| 影响 | 白屏，且现象"完全不像时序问题"，是本次最长的一轮返工 |
| 状态 | **RESOLVED** |

> ⚠️ **本冲突根因值得记住**：原理图**不体现** FSMC 时序这一层，只能靠实测 —— 属于方案 §1「AI 不能做、必须人来」的范畴。
